# PLP Python Week 4 Assignment

This repository contains my solutions for the Week 4 assignment.

## Files Description
* `welcome.py` - Contains a `welcome()` function that formats and returns a greeting for a given name.
* `toolbox.py` - A collection of three utility functions (`double`, `is_pass`, and `greet`) demonstrating basic arithmetic, conditional comparisons, and default parameter values.

## Reflection
The `greet` function in `toolbox.py` was the most challenging to write because it required understanding how default parameters work alongside string formatting.
